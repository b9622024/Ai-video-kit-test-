# brand.md：崇銘・體態管理

## 配色（暫定：系統預設「健康、知識、可信」，之後可換成你的品牌色）

| Token | 色碼 | 用途 |
|---|---|---|
| `--bg` | `#172A3A` | 深藍灰底色 |
| `--ink` | `#F4F1E8` | 主要文字 |
| `--r1` | `#E76F51` | 珊瑚紅：脂肪、警示 |
| `--r2` | `#F4A261` | 暖橘：次要強調 |
| `--r3` | `#E9C46A` | 芥末黃：**本集主角** |
| `--r4` | `#7FA7B8` | 灰藍：中性、對照組、肌肉 |
| `--muted` | `#A7B4BF` | 註腳、出處 |
| `--hi` | `#FFFFFF` | 光圈、膠囊標籤 |

做 composition 時，把上表的值寫進 `:root`，其餘照 design-system.md。

## 畫面偏好

- 人形用中性的簡單剪影，不畫真實身材對比照、不做身材羞辱的畫面。
- 圖解以**肌肉、脂肪、腰圍、餐盤**為主。
- 不畫產品。
